# Flor de Vida Agenda — Android

App interna del equipo de Flor de Vida Spa (Santa Marta, Colombia).
Se entra con un PIN que entrega la administracion. No es una app para clientas.

## Descargar para Android

El archivo de instalacion esta en **[Releases](../../releases/latest)**.

1. Abre ese enlace desde el telefono Android y descarga el archivo .apk
2. Toca el archivo descargado. Android pide permiso para instalar desde esta fuente: aceptalo.
3. Abre la app y entra con tu PIN.

Son 125 MB, asi que mejor con wifi. Es una sola vez: las actualizaciones
llegan solas al abrir la app.

## iPhone

En iPhone no se usa este archivo. La app esta en la App Store.
